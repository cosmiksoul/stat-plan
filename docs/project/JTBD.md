## Deferred (вынесено из скоупа MVP)

> User stories, которые были обсуждены и осознанно отложены.

- [ ] Sequential testing / mSPRT с always-valid CI — отложено в v2, нужна серьёзная методологическая работа (см. ADR-009)
- [ ] Heterogeneous treatment effects (causal forests, сегментные ATE) — слишком тяжело для клиентской реализации
- [ ] Power retrospective analysis — низкий приоритет, нужно только после нескольких прогонов реальных тестов
- [ ] Runtime-генерация demo-csv под точную конфигурацию плана — отложено, статических 4 файлов достаточно (см. ADR-007)
- [ ] Множественные тесты в одной сессии (switcher) — пока один активный тест в localStorage, см. open question в concept.md
- [ ] Сохранение истории прошлых тестов в localStorage — противоречит принципу «артефакты как состояние», пользователь сам коммитит в git
- [ ] CUPED variance reduction как обязательная фича — добавлена опциональная ячейка, но без полной поддержки в продвинутых параметрах
- [ ] Интеграции с BigQuery / Amplitude / Mixpanel — противоречит no backend (ADR-001)
- [ ] LLM-помощник для перефразировки гипотезы или объяснения результатов — отклонено в v1 (ADR-004)
- [ ] Авторизация / шаринг / командная работа — противоречит no backend
- [ ] Английская версия / билингва — открытый вопрос, ждём первых пользователей

## Post-MVP идеи

> Грубые наброски того, что может пойти в v2. Не обязательно user stories — могут быть направления.

- **Sequential testing.** Mixture Sequential Probability Ratio Test (mSPRT) или альфа-spending для подглядываний в результаты. Решает реальный pain — PM-ы всегда подглядывают, лучше дать им методологически корректный способ.
- **CUPED во весь рост.** Не опциональная ячейка, а полноценная поддержка pre-period covariates в брифе и data peek. Снижает требуемую выборку на 20-50%.
- **Калькулятор стоимости теста.** «Тест займёт 14 дней × 100K пользователей. Цена ошибки 1-го рода ≈ $X». Опциональная фича для коммерческих кейсов.
- **Библиотека шаблонов тест-планов.** Готовые шаблоны для типовых сценариев (новый CTA, рекомендательный блок, ценовая страница) — пользователь выбирает шаблон, видит, какие поля заполнены по умолчанию.
- **Heterogeneous treatment effects (light).** Эффект по сегментам new vs returning, mobile vs desktop — без полноценного causal forest, через простой бутстрап по сегментам.
- **Интеграция с git (push артефактов).** Кнопка «закоммитить в свой репо» — pull request с пакетом артефактов теста.
- **LLM-помощник в боковой панели.** Чисто для перефразировки гипотезы или объяснения статистических терминов, не для принятия решений. Опциональная фича.
- **Англоязычная версия.** При наборе аудитории за пределами рунета.
- **Поддержка кластерной рандомизации с расчётом ICC.** Сейчас показываем плановый sample size с warning «реальная выборка может быть в 1.5–5 раз больше» — после v1 можно добавить честный расчёт через data peek с колонкой кластера.
- **Stratified sample size.** Для случаев, когда стратификация заранее задана и есть данные по стратам.
- **Bayesian-режим.** Альтернатива frequentist подходу. Posterior probability вместо p-value, credible intervals вместо CI. Для команд, которые уже работают в этой парадигме.
