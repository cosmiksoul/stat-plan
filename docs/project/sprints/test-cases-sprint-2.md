## Как пользоваться

1. Открываешь URL, проходишь кейсы по порядку.
2. Каждому кейсу проставляешь статус: `ok` / `bug` / `skip`.
3. Если `bug` — описываешь в таблице Bugs found ниже (severity, шаги воспроизведения).

**Severity:** Critical / High / Medium / Low (см. Dev-Cycle.md фаза 6).

**Особое внимание:** кейсы 23, 26 — там уже найдены минорные баги при беглом осмотре (внесены в Bugs found). Кейсы 30-33 — реактивность карты и прогресса, новая логика. Кейсы 34-36 — Advanced collapsible, новый компонент. Кейсы 41-44 — регрессия Sprint 1.
