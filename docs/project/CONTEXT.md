Добавить минимальный ErrorBoundary или тестовый Provider-wrapper когда появятся первые RTL-тесты.

## Recurring questions

> Вопросы, которые периодически всплывают и заслуживают зафиксированного ответа (или ADR'а если они архитектурные).

- **Q:** Файлы в working tree обрезаются на середине UTF-8 символа после `git add .` на Windows. Что это?
  **A:** Зафиксирован один такой инцидент в Sprint 1 (`.gitignore`, `CLAUDE.md`, `README.md`). Возможные причины: сочетание Git `core.autocrlf=true` и какого-то фонового процесса, OneDrive sync, антивируса. Восстанавливается через `git checkout HEAD -- <files>`. Превентивно добавлен `.gitattributes` с `* text=auto eol=lf`. Если повторится — расследовать (`git config --list | grep autocrlf`, проверить, есть ли OneDrive в пути проекта, выключить antivirus на папке проекта).
